# 玩家面对面交易闭环

## Context

浏览器客户端已有服务端交易协议入口，但缺少地图玩家操作入口、交易室和完整回包处理，玩家无法通过 UI 完成交换。

## Change Summary

- 地图玩家菜单加入交易邀请，支持接受和拒绝。
- 增加双人交易室，展示双方形象、9 格物品、金币、聊天和确认状态。
- 物品拖放、堆叠数量、金币追加、双方确认、取消和服务端错误都接入 `PLAYER_INTERACTION` 协议。
- 交易展示状态和物品负载解析从 UI、通用物品解析器中分离，覆盖普通物品、装备和宠物分支。
- 任一方确认后冻结继续追加；关闭窗口会释放交易聊天焦点并恢复普通输入。
- linked server 在共享会话锁内校验报价并原子移出来源物品，拒绝确认后的修改、重复槽位和并发来源变化。

## Impact Surface

- 地图玩家点击交互
- 物品栏拖放
- 玩家交易收发包
- 游戏内窗口与输入状态

## Notes / Compatibility

交易合法性和最终结果以 linked server 为准；交易加锁和背包提交不新增数据库字段，也不直接操作数据库。
