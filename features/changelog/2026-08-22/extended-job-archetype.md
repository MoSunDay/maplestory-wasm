# 扩展职业主副属性原型对齐

## Context

职业主副属性原先直接按 `jobId / 100` 分支，只覆盖冒险家编号。骑士团和战神编号带有额外前缀，会落入未知职业并错误使用默认属性。

## Change Summary

- `JobProgression` 统一提供职业原型映射。
- 骑士团按去除 1000 前缀后的对应冒险家职业取主副属性。
- 战神职业族固定映射到战士原型。
- 回归验证同时覆盖转职阶段、新手技能族和职业原型。

## Impact Surface

- 骑士团与战神的主副属性选择
- 装备攻击力计算依赖的职业属性
- 职业阶段与新手技能映射验证

## Notes / Compatibility

冒险家职业映射不变；本次只修正扩展职业的客户端属性原型，不修改服务端角色数据。
