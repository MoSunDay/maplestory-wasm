# 现金商城全屏布局重排

## 背景

商城已切换为 2023 版 `CashShop.img` 全屏渲染，但首版直接沿用了 1024×768
素材中的零散坐标：顶栏货币与操作按钮偏挤，左栏分类下方留白，商品区和右栏
的边距不一致，详情/推荐区在 800×600 下出现文本越界；装备二级菜单则以浮层
盖住商品第一列。用户要求按 800×600 设计画布重新整理整个商城，同时保留
1280×720 下的等比缩放。

## 变更

### 布局与绘制

- `CashShopLayout.h` 统一为三列：左栏 4..94、商品区 100..496、右栏
  508..796；顶栏货币列间距 140px，操作按钮右锚到 x=790，搜索框、支付
  方式、卡片网格、翻页和详情区共用 12px gutter。
- 左栏改为完整 90×512 面板：8 个分类行高 22px，下方容纳图例、说明和
  操作提示；总宽仍为 800，避免 1024 素材坐标在缩小后产生半像素堆积。
- 搜索栏增加清除区，商品总数/筛选摘要独立成框；推荐面板改为 288×148，
  试穿人像、图标、价格和提示带分区绘制，不再与右栏槽位底部相互覆盖。
- 新增 `CashShopDraw.h`，集中 `draw_position` / `draw_size` / `fill_rect` /
  `outline_rect`、货币与页签文字定位等 inline 助手；`UICashShop.cpp`、
  `UICashShopPanels.cpp` 共用，绘制代码按职责拆分到 800 行限制内。
- 文本统一按 A11M 的实际 10px 字高居中；超宽商品名主动截断，避免
  `maxwidth` 只换行不裁剪导致卡片文字溢出。

### 装备子分类原位菜单

- 点击「装备」后，子菜单在原分类栏位置替换 8 个分类行，不再遮挡商品区；
  「← 返回」位于同级标题行，17 个子分类使用 21px 紧凑行，选中后自动收起。
- 子菜单展开期间分类按钮置为 inactive，避免命中框被原位子菜单覆盖时仍
  触发隐藏分类；返回后恢复分类栏和全部装备过滤。
- 分类计数、子分类计数、筛选摘要和状态探针同步刷新；切回「全部」恢复
  1984 件在售目录，武器/帽子子分类分别得到 180/338 件。

### 验收阻塞修复

- `ItemParser.cpp` 改为按封包条目类型字节分派 pet/equip/stackable 解析。
  此前 SET_FIELD 的 CASH 段按外层 InventoryType 推断，未加载的装备被当成
  普通物品读取，造成字节错位和 `Stack underflow`；修复后角色可正常进图。
- `CashShopSkin` 的第 3 个余额图标回退到 `nx_icon`，避免素材缺少
  `CSIcon/2` 时崩溃；`UICashShop` 余额绘制同步使用该图标。
- 搜索清除、筛选后重建目录使用 applied query，避免输入框文本和实际过滤
  条件在清除/刷新时短暂不一致。

## 验证

- Docker WASM Release 构建通过（`./scripts/docker_build_wasm.sh`）。
- 纯函数回归：`cash-shop-view`、`cash-shop-pet-category` 均 PASS。
- `cash-shop-equip-flow.mjs` 17 项全部 PASS：进图/开商城、1984 件目录、
  装备 1402 件、武器 180 件、帽子 338 件、选中行暖橙高亮、返回收起、
  重新展开、全部目录复原和 Escape 退出。
- `cash-shop-tryon-flow.mjs` 25 项 PASS：原位帽子/上衣/武器子菜单切换、
  累计试穿、人像像素变化与重置还原；`cash-shop-take-equip-flow.mjs`
  28 项 PASS：现金帽购买、仓库单次取出、物品栏穿戴和属性标记更新。
- `cash-shop-resolution-shot.mjs` 在 1280×720 与 800×600 下均完成截图，
  状态探针均为 `filtered=1984`，确认缩放布局可用。
- `cash-shop-pet-flow.mjs` 41 项检查全部 PASS：宠物分类 87 件、SN
  `60000001` 购买、仓库取出、召唤、地图自动捡取，以及断线重登后的
  自动回血回蓝。

## 不在范围

- 子分类选择不跨分类记忆，返回或切走即复位为「全部装备」。
- 未增加键盘遍历子分类；左栏鼠标/触控命中区域已覆盖完整行高。
