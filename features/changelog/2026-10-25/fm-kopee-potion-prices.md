# 自由市场科皮商店：药水价格调整

自由市场 910000000 的科皮（9201116 Kopee Relicseeker，shopid 1339）
稀有商店此前把两类高级药水定价得过于便宜，练级后期等于白送。本轮
只调价、不动商店结构：

| itemid | 物品 | 旧价 | 新价 |
|---|---|---|---|
| 2000005 | 超级药水（Power Elixir） | 5000（此前曾为 2000） | 50000（5w） |
| 2000004 | 特殊药水（Elixir / 万能药） | 2000 | 20000（2w） |

其余 30 个商品（飞镖、子弹、魔法石/召唤石、晨露/晚露、召回石等）
价格保持不变。

## 改动位置

价格仅存在于 `link_repos/MapleStory-Server/sql/custom_fm_service_npcs.sql`
的 `shopitems`（shopid 1339）两行：

```sql
(1339, 2000004, 20000, 0, 208),
(1339, 2000005, 50000, 0, 212),
```

客户端不需要任何改动：商店价格由服务端 OPEN_SHOP 封包下发，
WASM 客户端只按封包里的 `price` 渲染与扣款。

## 生效方式

该 SQL 可重复执行（幂等）：先 `DELETE FROM shopitems WHERE shopid
= 1339` 再整体重插，重复执行结果一致。但注意服务端 `MapleShopFactory`
在 JVM 内缓存商店对象，改 DB 后必须重启游戏服务端才会生效，只重跑
SQL 不重启的话玩家看到的仍是旧价。
