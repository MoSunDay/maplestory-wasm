# 新版本地图数据源 gate 检查（艾琳森林/时间神殿等暂缓）

任务 UI（见 [任务日志窗口](quest-log-window.md)）与自由市场玩法枢纽
（见 [玩法向导 NPC](fm-gameplay-guide-npcs.md)）都会把玩家送到新版本
地图（252 黄金寺院、262 玛加提亚扩展、271-273 时间神殿、300-305
艾琳森林、500/510/555/95x 等）。在这些区段落地之前先做阶段 0 的
数据源 gate，避免在缺数据的区段上继续排期。

## gate 1：wz 数据源扫描

对 `link_repos/2023年度冒险岛(1).7z`（8.4GB，079MAX4-2023 年度版）
做 `7z l` 列表扫描：上述区段的 `Map/*.img` 本体**全部不存在**，
仅 300000-300002 三张 079 时代的艾琳森林入口图在包内。

结论：数据源不具备。地图注入阶段 3 整体暂缓；这不阻塞任务 UI 与
玩法枢纽——向导可以先送到 079 已有的招募点/入口，后续数据到位后
再扩展目的地。

## gate 2：UI.nx 任务素材

`assets/UI.nx`（post-Chaos 组合包，1.15GB）中 `UIWindow2.img/Quest`
齐备：`list/backgrnd`（295×396）、`Tab` 0-3、`quest_info`、
`questState` 0/1 均存在，任务窗口素材无缺口。该结论已由
[任务日志窗口](quest-log-window.md) 条目消化为双代素材 dispatch。

## 后续路径

取得包含上述区段的 wz 数据源后：

1. 按 `tools/nx/inject_map_nx.py` 改造 manifest 模式，去掉对自由市场
   的硬编码，按区段批量注入；
2. 252 黄金寺院最小集 18 张起步，验证注入管线后再铺开其余区段；
3. 玩法向导菜单随注入进度逐步替换/补充目的地。
