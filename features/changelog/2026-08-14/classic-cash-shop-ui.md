# 老版商城双栏 UI

## 变更

- 现金商城改为严格使用现有 `UI.nx` 中 `UIWindow2.img/Shop` 的 465×328 老版背景、选择框、购买和退出按钮。
- 左栏提供在售商品筛选、分类、SN/名称搜索和分页；右栏在商城仓库与角色现金栏之间切换，并支持取出和存回。
- 将目录筛选、分页、分类/支付/右栏模式循环和金额格式化拆为纯函数模块。
- 从 linked server v83 商品和礼包 XML 生成内嵌目录，消除客户端 `Etc.nx` 与服务端 SN/商品/价格不一致造成的拒售。
- 取出响应兼容服务端未将部分任务物品标记为现金物品的情况，在不改变线上封包消费方式的前提下保留请求对应的 `cash_id`，保证物品可以再次存回商城仓库。
- 新增商城 WASM 只读验收探针与浏览器真实交易流程，逐步核对 NX Credit、仓库和角色现金栏数量。

## 验证范围

- 纯函数策略测试覆盖性别、在售、分类、名称/SN 搜索、分页边界和循环规则。
- NX/目录契约测试确认老版 Shop 背景与按钮状态完整，并确认 linked server 固定测试商品 SN `80000002` 为售价 1 NX 的在售非礼包商品。
- 浏览器流程完成真实购买、取出、存回和退出商城；仅用于既有 UI 测试账号，不发布生产版本。
