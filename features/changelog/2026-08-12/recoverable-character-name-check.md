# 创建角色名称校验可恢复

## 问题

创建角色提交名称时会禁用整个 UI，只有服务端名称响应才能解除；拒绝后输入框没有恢复焦点，响应丢失时则会永久停留在不可操作状态。

## 调整

- 名称校验改为角色创建界面的局部状态，不再全局禁用 UI。
- 非法或重复名称保留原输入、显示 NX 登录提示并恢复输入焦点，可直接修改后二次提交。
- 请求超过 8 秒自动恢复；迟到或不匹配的响应不会推进旧名称。
- WebUI 验收支持只验证“拒绝后重试并进入外观定制”，不创建持久化测试角色。

## 验证

- Docker WASM Release 构建成功。
- WebUI 验收脚本通过 Node.js 语法检查；当前运行环境在 GLFW 创建 WebGL 窗口阶段失败，未完成浏览器端流程验证。
