# 静默异步素材准备与阻塞提示

## Context

首次出现的贴图可能在绘制路径等待 NX 网络块、解压并上传，造成画面卡顿，同时用户无法区分程序停顿与正常加载。

## Change Summary

- WASM 中所有已实例化贴图统一静默异步预取，后台范围任务限制为 4 路并发。
- 图形主循环以每帧 2ms 扫描软预算寻找已到达贴图，并且每帧最多解压、上传一张；未就绪贴图暂时跳过，不同步等待。
- IndexedDB 缓存写入使用事务完成结果记账，持久预载会区分 `complete`、`degraded` 与 `failed`，不再把权限未获批或写入失败误报为完整持久缓存。
- 当前画面实际需要尚未驻留的贴图时，将静默预取提升为前台任务并显示玻璃化“素材加载中...”遮罩。
- 前台素材失败后保留明确错误提示和“重试”入口；成功后关闭遮罩并恢复交互。

## Impact Surface

- LazyFS 前台读取与后台预取调度。
- 纹理解压、WebGL 图集上传和首次绘制行为。
- Web 页面运行时加载反馈及输入拦截。

## Notes / Compatibility

- 本地缓存命中和批量后台预取不显示遮罩；同一范围从后台升级为前台时复用原请求。
- 启动页仍可见时不进入运行时重试遮罩，启动素材失败继续落入现有启动错误页，避免重试 UI 被启动页遮挡。
- 不修改 NX 素材或资源服务协议。
