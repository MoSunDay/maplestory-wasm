# 标准死亡墓碑动画

## Context

角色死亡此前只切换为倒地姿态并立即弹出英文回城提示，没有呈现素材中的标准墓碑落下过程，用户容易将死亡反馈误判为 UI 显示异常。

## Change Summary

- 本地玩家和其他玩家进入死亡状态时统一播放 `Effect.nx/Tomb.img/fall`，播放完成后持续显示 `land/0`。
- 回城确认框延迟到墓碑落地后出现，文案调整为 `你已死亡。点击“确定”移动到最近的城镇。`。
- 确认后沿用现有回城协议，复活或离开死亡状态时清除墓碑。
- 客户端初始化时校验标准墓碑素材，素材不完整则直接报告错误。

## Impact Surface

- 角色死亡状态与效果渲染。
- 本地玩家死亡后的回城确认时机和中文文案。
- `Effect.nx` 启动校验。

## Notes / Compatibility

- 使用标准 `Tomb.img`，不使用升级墓碑效果。
- 未改动服务端协议、服务端代码或 `assets/` 内容。
