# 现金商城核心闭环

## Context

客户端已有状态栏商城入口和按键动作，但没有发送进入请求、商城 UI、协议响应处理或返回游戏流程，玩家无法使用 Cosmic 已提供的商城能力。

## Change Summary

- 接通进入商城、余额查询、商城初始化和退出回服协议。
- 从只读 NX 数据建立真实在售商品与礼包目录，提供分类、搜索、翻页和三类支付来源。
- 支持普通商品/礼包购买，以及商城仓库与角色物品栏之间的现金物品双向转移。
- 保留现金物品唯一 ID，商城操作成功后同步本地仓库/物品栏；失败时展示明确错误并解除请求锁。
- 返回频道后复用完整角色快照解析，恢复角色进度、地图与游戏 UI。

## Impact Surface

- 状态栏和商城快捷键入口。
- 现金商城 UI 状态、商品模型和物品唯一 ID。
- 商城相关收发封包、频道重连和完整角色快照恢复。

## Notes / Compatibility

- 仅修改客户端，没有修改服务端、数据库或 NX 素材。
- 当前范围不包含礼物、愿望单、优惠券、栏位扩充、退款和商城惊喜包。
