# 攻击特效补齐与重复攻击修复

## Context

攻击施放已有基础效果，但多段、多目标、斗气终结和属性充能未完整映射到 NX 分支；同时固定帧循环会在攻击键保持按下时反复发起普通攻击。

## Change Summary

- 普通攻击改为按键按下时触发一次，不再由固定更新循环无限续接。
- 多段和多目标技能按实际伤害段或目标选择对应的 NX 命中特效。
- 斗气终结技按可消耗斗气数量播放 `finish` 特效。
- 属性攻击按火、冰、雷、圣充能来源播放对应施放特效。
- 本地与其他玩家共享一致的可见攻击特效选择逻辑。
- 攻击边沿、特效分支、远端 Buff 位序及全量 `Skill.nx` 结构均有独立验证入口。

## Impact Surface

- 本地与其他玩家的攻击施放及命中特效。
- 普通攻击按键触发时机。

## Notes / Compatibility

- 不修改服务端、伤害计算、目标选择和攻击封包格式。
- 不修改 `assets/`，只读取现有 `Skill.nx` 素材。
