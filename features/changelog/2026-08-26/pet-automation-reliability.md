# 宠物拾取、跟随与自动补给可靠性

## Context

永久新手宠物已具备自动化能力，但客户端会在服务端新掉落保护期内过早发送一次拾取并立即放弃目标；跟随只使用单一水平死区，残留物理速度、跨平台目标和无进展移动会造成走停抖动或卡图。首次修复仍把任意 4 像素位移当成进展，碰撞往返会持续重置脱困计时。宠物选项页也只能设置阈值，玩家无法直接查看和选择实际自动 HP/MP 药品。

## Change Summary

- 把跟随启停迟滞、远距离/垂直脱困和无进展恢复提取为纯策略；只有与当前目标距离至少缩短 4 像素才算有效进展，碰撞往返最终会触发脱困；待机、传送与远端姿态切换同步重置运动或动画状态。
- 宠物脱困移动立即同步，且同帧先发移动再发拾取；首个拾取等待服务端 400ms 保护期，失败后按间隔最多尝试三次，不再一次请求后放弃仍存在的掉落。
- 宠物自动补给面板同时提供 HP/MP 阈值、当前 USE 背包恢复药品候选、数量与 `OFF` 选择；确认时重新校验库存，并沿用现有键位协议保存角色药品选择。
- 增加纯策略回归与 WebUI 只读探针，覆盖选择循环、门禁/冷却、跟随迟滞、卡住脱困、拾取保护期与重试。两阶段真实流程经 NPC 商店购买红/蓝药并保存配置，重连后验证实际药品消耗、资源恢复、真实怪物掉落目标转换、当前角色宠物的服务端确认拾取和跟随稳定性；浏览器以正常关闭保证本地阈值落盘。

## Impact Surface

- 首只已召唤宠物的地面跟随、跨平台脱困和移动同步
- 金币/物品自动拾取请求时序
- 宠物自动 HP/MP 药品选择与阈值设置
- WebUI 宠物专项验收入口

## Validation

- 宠物纯策略测试、目标距离进展回归和 UBSan 极端坐标检查通过。
- Emscripten Release WASM 完整编译和链接通过。
- `configure` 真实 WebUI 阶段通过：正常 NPC 商店购买 `2000000`/`2000003` 各 20 个，保存 HP/MP 药品与 98% 阈值，跟随距离 35.2 像素、有效反转 0、浏览器异常 0。
- `runtime` 重连阶段通过：低血低蓝均实际消耗药品并恢复至满值；真实怪物产生 2 个掉落，观察到宠物目标转换及当前角色宠物的服务端确认拾取；跟随距离 98.8 像素、有效反转 0、浏览器异常 0。

## Notes / Compatibility

不新增数据库表、环境变量或游戏资源，不改变现有宠物能力门禁及服务端最终权限校验。药品选择继续使用既有角色键位数据，阈值继续使用浏览器本地存储。
