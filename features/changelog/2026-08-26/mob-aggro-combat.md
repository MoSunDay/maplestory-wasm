# 怪物仇恨追击与技能战斗

## Context

怪物受击后缺少持续追击和主动攻击闭环，客户端也未消费服务端的怪物动作响应、状态、疾病与雾封包；服务端旧链路对动作序列、攻击范围、技能建议和重复命中缺少统一权威校验。

## Change Summary

- 怪物按累计伤害选择仇恨目标，受击后立即切换控制者并追击，平局保持当前目标。
- 客户端从 NX 驱动地面/飞行追击、跳跃、普通攻击和技能动画，在效果帧重新校验命中范围。
- 服务端统一校验控制者、序列、WZ 动作/范围、冷却、MP、忙碌窗口、单次技能建议和逐角色命中窗口。
- 补齐怪物强化、免疫、硬皮、物理/魔法反伤，以及玩家疾病、雾区域和恐惧视野表现。
- 增加纯决策、动作编码、暴击位往返、混乱输入锁存、伤害门禁、确定性仇恨和全量 Mob/Skill NX 审计。

## Impact Surface

怪物控制权与移动、玩家受击、怪物技能、Buff/疾病、雾渲染、物理/魔法伤害预测，以及 linked server 的怪物动作和玩家攻击结算。

## Notes / Compatibility

- 继续使用 v83 既有 opcode，不新增数据库表或环境变量。
- NX 审计发现 1 个攻击与 7 个技能绑定缺少必要动画/范围；两端均明确禁用这些数据声明，不执行无视觉或无限范围降级。
- 未执行线上发布。
