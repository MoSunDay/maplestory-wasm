# 怪物出生位置协议对齐

## Context

地图资源中的怪物出生点分布在不同横坐标和平台，但客户端进入地图后把怪物集中到局部区域。服务端在怪物坐标前写入固定 22 字节出生状态块，客户端却按另一种 16 字节状态掩码布局读取，剩余零字节因此被误读为坐标 `(0, 0)`。

## Change Summary

- 怪物普通出生和控制权出生统一按 linked server 的固定状态块解析。
- 坐标、姿态、foothold、出生特效、父怪物和队伍字段由独立纯解析模块一次性消费。
- 覆盖假怪及其显形布局，未知或截断封包不再降级为默认字段。
- 增加基于服务端实际字节布局的独立协议回归验证。

## Impact Surface

怪物初次进入视野、刷新后重生、控制权切换、特殊出生和假怪显形。刷怪数量、刷新周期、地图 WZ 出生点和服务端逻辑保持不变。

## Notes / Compatibility

- 以仓库配套 `link_repos/MapleStory-Server` 的出包实现为协议来源。
- 不涉及数据库、环境变量或线上发布。
