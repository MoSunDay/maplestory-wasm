# 废弃都市组队任务客户端补全

## 问题

废弃都市组队任务的服务端脚本、地图和奖励链路已经存在，但客户端没有处理场地计时器、停止计时、开门对象和成功/失败音效。空格键也没有执行附近 NPC 对话，导致任务即使能进入，关键反馈与操作仍不完整。

## 修复

- 接入 `CLOCK` 与 `STOP_CLOCK`，增加顶部场地时钟；倒计时使用单调时间并在零点隐藏。
- 补齐 `FIELD_EFFECT` 的组队任务模式：按名称关闭 `gate` 地图对象、播放一次性成功/失败画面，并兼容 `Party1/Clear`、`Party1/Failed` 的 `Sound.nx/Field.img` 路径。
- 空格键会选择交互范围内最近的非鼠标专用 NPC，发送与鼠标点击相同的标准对话请求。
- 增加只读 WASM 探针，覆盖地图、坐标、其他玩家、怪物、道具数量、NPC 文本、计时器和具名地图对象，供多客户端验收使用。

## 验证

- WASM Release 制品完整编译成功。
- 真实浏览器从登录、世界/频道、角色选择进入游戏成功；地图素材安全门释放，浏览器异常为 0。
- 纯函数验证覆盖倒计时、跨日时钟和格式化。
- NX 素材验证确认 5 张任务地图均有唯一 `gate`，成功/失败音效可解析。
- 服务端契约验证确认 3–4 人、21–30 级、30 分钟、五阶段地图与传送门、怪物数量、券/通行证掉落及奖励脚本完整。

真实四客户端从建队到击杀绿水灵并进入奖励地图仍需要已授权的 GM6 测试身份来准备随机隔离账号；验收工具不会修改鉴权数据库或降低权限门槛。
