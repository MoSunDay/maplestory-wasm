# 新角色与存量角色永久宠物自动化

## Context

角色四维已经统一为 `20/20/20/20`，但新手仍需自行取得宠物及其基础能力；客户端也没有实现宠物主动拾取、自动药水选择和阈值设置的完整闭环。

## Change Summary

- 新角色创建事务内赠送永久 Brown Puppy（`5000001`），并将金币磁铁、物品袋、自动 HP/MP 药水袋和飞行靴放入隐藏的已装备宠物能力槽。
- 存量角色首次登录时按版本幂等补发；现金栏满时不写入部分礼包，提示腾出空间后重登重试。
- 现金栏双击宠物可召唤；宠物主动追踪有权限且匹配能力的掉落，客户端同步移动，服务端复核归属、距离和能力后拾取。
- USE 栏药水可拖到宠物装备面板的 HP/MP 槽；系统菜单可分别设置 1%–99% 阈值，默认 50%，保存到浏览器本地存储。
- 自动补给每个请求只消耗一个当前槽位药水，服务端校验召唤宠物、角色药水选择、能力装备、物品类型和实时库存。
- 所有角色创建配方继续由服务端统一初始化 STR、DEX、INT、LUK 为 20，并清理职业配方残留覆盖。

## Validation

- WASM Release 全量构建通过。
- linked server 全量 Java 编译通过。
- 宠物自动补给纯函数验证覆盖阈值边界、能力门禁、单次药水、冷却和 HP/MP 合并药水。
- NX 审计确认 Brown Puppy、五项宠物能力及经典 OptionMenu/Equip pet 素材存在。

## Impact Surface

- 客户端宠物显示与移动、掉落选择、背包拖放、系统选项、宠物封包。
- linked server 角色创建、首次登录补发、宠物拾取/药水校验及 `characters` 表迁移。
- 不自动召唤宠物，不修改已有角色四维，不删除任何数据库数据。
