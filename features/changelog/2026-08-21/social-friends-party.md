# 好友与组队完整闭环

## Context

客户端原先没有可用的好友窗口，好友回包被忽略；组队只保留部分显示和命令，缺少完整成员操作及稳定的双端状态验收。

## Change Summary

- 新增独立 Buddy 窗口和窗口无关的好友/队伍纯状态模型。
- 接入好友列表、请求、频道和容量事件，以及添加、接受、拒绝、删除、上下线同步和好友聊天。
- 补全队伍创建、邀请拒绝/接受、成员快照、HP、队聊、队长转让、踢出、退出和解散。
- linked server 修正可见好友计数、接受后的双端全量同步和 UTF-8 定长字段，并允许同等级范围的新手角色组队。
- 双 Chromium、双真实账号流程覆盖完整好友与组队生命周期；测试账号凭据只保存在 git 忽略的运行时文件。

## Compatibility

复用 v83 既有好友、组队和多目标聊天 opcode；未新增环境变量、数据表或数据库迁移，也不删除现有数据库数据。
