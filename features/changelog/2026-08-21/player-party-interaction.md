# 地图玩家点击接入组队邀请

## Context

游戏内鼠标分发只检查 NPC，没有对同地图远端玩家做命中测试；组队窗口还把邀请按钮限制为已经入队后才可用。因此点击人物没有反馈，单人也无法使用服务端已经支持的“邀请时自动建队”。

## Change Summary

- 增加纯函数玩家命中策略，统一处理摄像机偏移、固定人物点击区域和重叠人物的最近目标选择。
- 地图内悬停远端玩家时显示可点击光标，点击后打开并置顶组队窗口。
- 点击已有队员会选中对应成员；点击队外玩家会预填并全选角色名，明确提示点击 Invite 发送邀请。
- 单人状态开放 Invite，复用 linked server 的邀请时自动建队能力。

## Impact Surface

- 游戏地图鼠标输入、远端玩家选择和组队窗口邀请入口。
- 不修改服务端、数据库、组队封包格式或 NPC 点击行为。

## Validation

- 玩家命中纯函数覆盖摄像机偏移、空白区域、重叠人物最近目标和候选顺序无关性。
- 社交协议及组队状态验证继续通过；WASM Release 构建作为集成验证。
