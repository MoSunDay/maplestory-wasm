# 普通攻击挥砍残影与手套分层修复

## Context

普通近战刺击能够显示残影，但三种挥砍姿态的单帧素材只声明 `a1=0`，旧动画解析把它当成起止透明度均为 0，导致绘制流程执行却没有可见像素。手套素材同时存在多组身体、头部、衣袖、武器和头发相对层，未识别的层此前全部落入默认手套层，攻击姿态下会把左右手部件叠成重影。

## Change Summary

- 仅声明透明度终点的动画帧改为从默认 255 向 `a1` 过渡，恢复 `swingO1`、`swingO2`、`swingO3` 的蓝白挥砍弧光。
- 残影在姿态更新后观察前后身体帧，终止帧不会因姿态回绕而漏触发；复制预热模板时重置播放状态。
- 一次性残影只有在非零透明贴图实际提交渲染后才允许推进，素材延迟或图集恢复期间不会消耗播放窗口。
- 手套与护腕完整映射 Base zmap 的 14 个层级；已知 Character NX 部件不再退回默认层，左右手按正确相对层各绘制一次。
- WebUI 验收逐帧记录刺击/挥砍姿态、身体帧和实际呈现状态，并保留连续合成帧供视觉抽检。

## Impact Surface

本地玩家与远端角色共用的普通近战残影、通用 NX 动画透明度端点，以及角色手套外观分层。服务端协议、数据库、环境变量和 NX 原始数据不变。

## Validation

- 236 件手套、40208 个位图部件及 Base zmap 14 个手套标签审计通过。
- 589 把近战武器、2534 个攻击姿态和 160 个残影档位回退审计通过。
- WASM Release 制品构建通过；真实 WebUI 连续执行 20 次普通攻击，刺击与三种挥砍均提交非零透明残影，无素材遮罩、浏览器异常或运行时错误。
- 合成帧抽检确认 `swingO1`、`swingO2`、`swingO3` 弧光可见，攻击姿态手套未出现默认层重叠。
