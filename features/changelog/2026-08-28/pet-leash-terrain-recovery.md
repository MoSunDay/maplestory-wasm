# 宠物 300px 安全绳与实际碰撞脱困

## Context

旧跟随策略曾在宠物距主人超过 150px、垂直差超过 90px 或普通跟随卡住时直接瞬移；改成停滞计时后，斜坡上的纵向变化又会被误判为没有接近目标，导致宠物错误起跳、脱离 foothold 并持续下坠。

## Change Summary

- 主人安全绳统一为二维距离大于 300px；300px 边界内不会因垂直差或卡住而瞬移。
- 150px 垂直差只判断拾取目标可达性，不参与主人安全绳。
- 地面宠物对齐人物普通移动，不启用边缘转向；连续斜坡保持 foothold 贴合，平台末端自然下落。
- 共享物理层返回当帧真实碰撞结果；只有水平移动实际撞墙并完全受阻才触发定向跳跃，距离停滞和边缘预判不再触发跳跃。
- 拾取目标连续三次真实受阻跳跃仍无进展后放弃；主人跟随只在真正越过 300px 时回到主人侧。
- 跟随和拾取距离改用 64 位中间值，避免极端地图坐标的平方溢出。

## Impact Surface

宠物地面/飞行跟随、foothold 碰撞、拾取目标重试、移动同步、地图掉落距离计算及浏览器验收探针。

## Notes / Compatibility

继续使用现有 v83 宠物移动与拾取协议；未新增数据库字段、环境变量或资源文件，也不改变服务端拾取裁决。
