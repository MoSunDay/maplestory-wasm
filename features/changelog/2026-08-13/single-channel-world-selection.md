# 单频道世界选择与确认入口

## Context

服务端会报告多个容量频道，客户端因此显示了 3 个频道；确认按钮路径又没有被浏览器流程验收覆盖，用户可能停留在世界选择页。

## Change Summary

- 客户端在服务端至少有一个频道时只显示并选择频道 1，对协议固定发送零基频道 ID `0`。
- 保留确认按钮和双击频道两种进入方式；浏览器全流程改为单击可见的 `Go To Selected Channel` 按钮后验收角色选择状态。
- 新增纯函数频道策略和只读 NX 元数据验证，覆盖零频道、单频道及多频道输入。

## Impact Surface

登录流程的世界/频道选择 UI 与对应回归验证。

## Notes / Compatibility

此变更只限制客户端公开入口，不修改 Cosmic 的频道配置、端口或服务端行为。服务端未报告可用频道时，确认按钮仍保持禁用。
