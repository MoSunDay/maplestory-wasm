# 现金商城

## 能力

角色可从游戏状态栏或商城快捷键进入 linked server 现金商城。商城读取由 linked server v83 `Commodity.img.xml` 与 `CashPackage.img.xml` 生成并随 WASM 内嵌的商品清单，结合客户端字符串资源形成目录，并以服务端下发的特殊商品状态、三类余额和商城仓库为准。目录文件缺失或验收商品契约不符时直接报错，不回退到与服务端 SN 不一致的客户端 `Etc.nx` 商品表。

商城界面按 2023 高版本 `CashShop.img` 素材做全屏现代渲染：`Base/backgrnd` 1024×768 背景拉伸铺满视口，商品以 `CSList` 卡片 4×3=12 网格陈列（选中卡片出现 `BtBuy` 购买按钮），搜索栏复用 `CSSortBar`，右栏以 `CSInventory` 面板 7×3=21 槽位在商城仓库和角色现金栏之间切换，余额用 `Base/Number` 位图数字显示，翻页与转移分别使用 `CSBargainSale`、`CSLockerNew` 按钮。`CSEffect` 徽章与左侧图例、分类件数与筛选摘要、余额图标、卡片期限、右栏多字段详情和 `Base/Preview` 推荐面板补充了可见信息，推荐面板以「玩家当前外观 + 试穿集」叠加渲染人像（高亮可试穿或试穿集非空时展示，否则回退商品图标），CharLook 无可见层的槽位仍回退商品图标；槽位使用 `backgrndCover` 半透明格底。全部坐标基于 800×600 设计空间，桌面窗口其它尺寸时整体等比缩放居中。所需现代素材缺失或尺寸错误会直接终止并报告，不降级到老版商城素材。

## 规则与流程

- 只展示当前在售且符合角色性别的商品；左侧分类列、搜索栏与支付来源三选（NX Credit、Maple Point、Prepaid NX）驱动筛选，支持名称或 SN 搜索及滚轮/按钮翻页。
- 选中或再次点击左侧「装备」分类会展开装备子分类菜单：全部装备、帽子、脸饰、眼饰、耳环、上衣、套装、裤子、鞋子、手套、盾牌、披风、戒指、坠饰、腰带、勋章、武器，按物品 ID 槽位映射并显示各类在售数量；切换其他分类时菜单收起并复位为全部装备。
- 点击目录卡即试穿：试穿集按选择顺序叠加到玩家外观上（预览用），同槽位后选覆盖先选、不同槽位累计；可试穿槽位为帽/脸饰/眼饰/耳环/上衣/套服/下装/鞋/手套/披风/盾/武器，戒指/坠饰/腰带/勋章等无可见层槽位回退商品图标。
- 推荐面板「重置」按钮清空试穿集、人像还原玩家原始外观（试穿集为空时按钮置灰）；点击推荐面板选中当前页高亮项，不重置分页/搜索。
- 装备子分类浮层选中后自动收起（点击分类栏「装备」可重新展开），避免浮层遮挡目录第一列卡片——此前正是「试穿不生效」的直接原因。
- 支持 NX Credit、Maple Point、Prepaid NX 三类支付来源；购买前显示商品、价格和支付来源确认。
- 普通商品和礼包使用各自的服务端操作，成功后加入商城仓库，并等待服务端余额同步。
- 商城仓库与角色现金栏槽位支持双击转移：双击仓库格取出、双击现金栏格存回；单击只选中，转移按钮也可用。成功后的自动选中不会让双击第二下再次逆向转移。
- 商城仓库物品可取回角色对应物品栏，装备取出后进入 EQUIP 栏并刷新装备栏、物品栏与角色属性；在物品栏双击该格即可穿戴，已装备栏与属性同步更新。角色物品栏中带有效 `cash_id` 的未装备现金物品可存回商城仓库。
- linked server 对部分现金商城任务物品不会在线上物品体中标记现金属性；取回时客户端保留该次操作对应的商城唯一 ID，使这类物品仍可正常存回仓库。
- 购买或转移成功后自动切到目标右栏并选中新物品，允许在同一界面连续验证“购买—取出—存回”；自动选中只影响高亮，不改变双击的转移方向。
- 退出时回到原频道，重新应用服务端完整角色快照，再恢复游戏地图和 UI。

## 状态与错误面

- 购买和转移期间锁定重复操作，收到成功或错误响应后解锁。
- 余额不足、性别限制、仓库或角色物品栏已满、商品不可售、库存不足、商城不可用和每日限额等错误直接显示服务端语义，不伪造成功状态。
- 回服地址被拒绝或连接失败时保留商城界面并恢复输入，显示明确错误。
- 浏览器专项验收使用 linked server 固定商品 SN `80000002` 发起真实交易，并通过客户端只读状态探针核对每一步余额和物品数量变化；`cash-shop-take-equip-flow.mjs` 另用 SN `20000016` 覆盖「仓库双击取出→物品栏双击穿戴」，`cash-shop-tryon-flow.mjs` 覆盖累计试穿与重置。
- 礼物、愿望单、优惠券、扩充栏位、退款和商城惊喜包不在当前能力范围内；若收到未知商城响应，会显示响应码并记录诊断。
