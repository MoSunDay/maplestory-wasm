# 现金商城

## 能力

角色可从游戏状态栏或商城快捷键进入 linked server 现金商城。商城读取由 linked server v83 `Commodity.img.xml` 与 `CashPackage.img.xml` 生成并随 WASM 内嵌的商品清单，结合客户端字符串资源形成目录，并以服务端下发的特殊商品状态、三类余额和商城仓库为准。目录文件缺失或验收商品契约不符时直接报错，不回退到与服务端 SN 不一致的客户端 `Etc.nx` 商品表。

商城界面复用老版本 `UIWindow2.img/Shop` 的 465×328 背景、选择框、购买和退出按钮；左栏固定显示商品目录，右栏可在商城仓库和角色现金栏之间切换。所需老版素材缺失或尺寸错误会直接终止并报告，不降级到现代商城素材。

## 规则与流程

- 只展示当前在售且符合角色性别的商品，支持分类、名称或 SN 搜索及翻页。
- 支持 NX Credit、Maple Point、Prepaid NX 三类支付来源；购买前显示商品、价格和支付来源确认。
- 普通商品和礼包使用各自的服务端操作，成功后加入商城仓库，并等待服务端余额同步。
- 商城仓库物品可取回角色对应物品栏；角色物品栏中带有效 `cash_id` 的未装备现金物品可存回商城仓库。
- linked server 对部分现金商城任务物品不会在线上物品体中标记现金属性；取回时客户端保留该次操作对应的商城唯一 ID，使这类物品仍可正常存回仓库。
- 购买或转移成功后自动切到目标右栏并选中新物品，允许在同一界面连续验证“购买—取出—存回”。
- 退出时回到原频道，重新应用服务端完整角色快照，再恢复游戏地图和 UI。

## 状态与错误面

- 购买和转移期间锁定重复操作，收到成功或错误响应后解锁。
- 余额不足、性别限制、仓库或角色物品栏已满、商品不可售、库存不足、商城不可用和每日限额等错误直接显示服务端语义，不伪造成功状态。
- 回服地址被拒绝或连接失败时保留商城界面并恢复输入，显示明确错误。
- 浏览器专项验收使用 linked server 固定商品 SN `80000002` 发起真实交易，并通过客户端只读状态探针核对每一步余额和物品数量变化。
- 礼物、愿望单、优惠券、扩充栏位、退款和商城惊喜包不在当前能力范围内；若收到未知商城响应，会显示响应码并记录诊断。
