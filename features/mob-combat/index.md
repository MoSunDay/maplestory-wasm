# 怪物仇恨战斗

## 能力

怪物受到有效伤害后会将攻击者加入仇恨表，并追击当前累计伤害最高的存活玩家；最高仇恨相同时保留当前目标。控制权随目标切换，使被追击玩家的客户端负责产生移动意图，服务端负责最终授权。

## 行为规则

- 地面怪向目标水平追击，目标位于可达高处且怪物具有跳跃动作时会跳跃；飞行怪同时追踪水平和垂直位置。
- 目标进入 WZ 普通攻击范围且攻击可用时，怪物播放对应 `attack1..attack9`，在 `effectAfter` 时命中；技能建议有效且目标在技能范围时，技能优先。
- 服务端按控制者、递增序列、精确动作、朝向/范围、MP、冷却和忙碌窗口校验动作。技能必须消费服务端上一次响应给出的单次建议，客户端不能自行选择技能。
- 普通攻击对每名角色每个动作最多命中一次；客户端无敌期间到达的命中会被消费而不延迟补伤害。
- 怪物免疫、硬皮、攻击/防御/回避/速度强化与物理/魔法反伤按攻击类型生效。硬皮逐段仅接受暴击伤害，客户端封包往返保留每一段的暴击标志。
- 怪物技能可施加既有疾病及药水封锁、暗影和恐惧；雾技能显示服务端同步的作用区域。

## 状态与错误

- 怪物失去控制权或死亡后停止本地决策，动作执行期间暂停产生新决策；仇恨条目过期时服务端重新选择存活目标，无仇恨时复位。
- 失去控制权或死亡会同时取消尚未到效果帧的本地命中，避免控制权切换后补发过期伤害。
- 不完整或过期的移动、越权技能、错误动作索引、重复命中和超范围命中会被服务端拒绝。
- NX 中缺少动画或攻击范围的声明会明确记录并禁用，不会用错误动画或无限范围降级执行。
