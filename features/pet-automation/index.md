# 永久新手宠物与自动化

## 能力

每个新角色在创建事务内获得一只永久 Brown Puppy（`5000001`），并具备金币磁铁、物品袋、自动 HP/MP 药水袋和飞行靴能力。存量角色在首次登录时按礼包版本幂等补发；即使已有同类宠物仍会收到本角色礼包。

宠物不会自动召唤。玩家在现金栏双击宠物后，已召唤的首只宠物会主动追踪可拾取的金币或物品；跟随采用启停迟滞，距离过远、垂直不可达或持续未接近目标时会就近脱困，碰撞造成的往返位移不会被误判为有效进展，也不会在目标边缘反复切换走停动画。客户端先同步宠物位置，再在服务端新掉落保护期结束后请求拾取；单次失败会限次重试。linked server 最终复核宠物身份、掉落归属、距离和能力，拒绝玩家主动丢弃的物品及无权限目标。

## 自动补给

- 玩家既可把 USE 栏中具备对应恢复效果的药水拖到宠物装备页 HP 或 MP 槽，也可在系统菜单的宠物自动补给面板中按当前背包候选切换；选择 `OFF` 可单独关闭 HP 或 MP 自动药水。药品选择按角色保存在服务端键位数据中。
- 宠物自动补给面板同时配置 HP/MP 触发阈值，范围 1%–99%、默认 50%，阈值保存在当前浏览器本地存储中。
- 只有角色存活、宠物已召唤、对应自动药水能力存在且实时背包仍有选中药水时才发送请求。
- 单个请求只消耗一个药水；同一药水同时恢复 HP/MP 时合并为一次请求，分别选药时 HP 优先、MP 在后续冷却允许时处理。

## 状态与错误

- 存量角色现金栏已满时不发放任何部分礼包，提示至少腾出一格并在下次登录重试。
- 本地阈值读取失败回到 50%；保存失败直接提示且不更新当前运行时阈值。
- 打开设置或确认保存时会重新校验药品仍存在且具有对应恢复效果；已移除或不匹配的选择转为 `OFF`，不会向服务端提交无效物品。
- 服务端补发事务或角色加载失败时终止本次登录，不以缺失能力的降级状态继续。

## 约束

- 不修改存量角色四维；所有新角色创建配方继续初始化 STR/DEX/INT/LUK 为 20。
- 使用现有 v83 宠物、能力、宠物装备页和物品图标，不新增游戏资源。
- 上线前必须先应用 linked server 的 `characters.starter_pet_grant_version` 迁移。
