# 永久新手宠物与自动化

## 能力

每个新角色在创建事务内获得一只永久 Brown Puppy（`5000001`）和五项隐藏能力装备；宠物也可在现金商城「宠物」分类直接购买（见 [现金商城](../cash-shop/)）。无论来源或发放版本，只要召唤的是宠物（物品 ID `5000000–5000999`），客户端与 linked server 都把金币磁铁、物品袋、飞行靴和自动 HP/MP 药水袋视为宠物内建能力；魔法秤仍必须由实际装备提供。存量角色继续在首次登录时按礼包版本幂等补发，不做宠物来源迁移。

宠物不会自动召唤。玩家在现金栏双击宠物后，已召唤的首只宠物追踪主人或主人 120px 范围内的可拾取掉落；地面移动与跳跃完全采用主人当前 SPEED/JUMP 属性对应的走力与跳力（`MovementProfile`），移动逻辑与人物一致，人物到不了的地方宠物也不会去。宠物与主人二维距离只有在大于 300px 时才瞬移到主人左侧 35px，垂直差（主人低于宠物）不会绕过该门槛；非拾取状态下主人位于宠物头顶超过追击上限（基础 88px）时立即瞬移回主人身边，不等 300px 门槛，消灭"在平台底下爬行"阶段。每次瞬移都会把宠物重锚到主人当前 foothold（onground、坡度、图层随之一并复位），不会再带着旧的下层地板 id 判定重力而"传回主人身边又立刻坠落到下层"。地面宠物复用角色 foothold、墙体、斜坡和重力计算；跟随主人（无拾取目标或目标不在下方）时保持 TURNATEDGES 边缘纪律，走到平台末端会停下而不是走出边缘坠落；只有拾取目标明确在下方（dy > 16px）时才解除边缘纪律允许落体俯冲，只有收到水平移动指令后实际撞墙且没有沿指令方向前进时才以与人物相同的起跳定向跳跃（一次垂直冲量加起跳前走动惯性，空中无水平操控），距离停滞、斜坡高度变化和边缘预判均不会触发跳跃。高于主人单跳可达高度（基础 88px，随 JUMP 属性提升，按共享重力 0.14 计算）或深于 240px 的拾取目标直接放弃，其余拾取目标连续三次真实受阻跳跃仍失败后放弃，宠物绝不瞬移到物品旁；拾取目标位置每帧跟随掉落实时位置刷新（掉落下落与散落不再让宠物停在过时坐标上）；宠物停驻后按可达窗口判定拾取：水平 50px、向下 96px、向上不超过 88px 追击上限，脚下图标偏移与下一层平台的掉落均可拾取；窗口外追击超过约 240 帧仍不可达才放弃并拉黑该掉落直至其消失，不再呆站也不饿死其余掉落，也不会把还在下落途中、即将落进拾取窗口的掉落提前拉黑。客户端先同步主人侧瞬移位置，再在服务端新掉落保护期结束后请求拾取：宠物进入可达窗口后按最近优先一次请求最多 4 件窗口内的可拾取物，成簇掉落一次扫净，重试与冷却节奏不变；宠物自行放弃的目标同样进入冷却，避免同帧重复选中。linked server 最终复核宠物身份、掉落归属、60px 宠物距离和对应能力，拒绝玩家主动丢弃的物品及无权限目标。服务端确认拾取后，客户端立即结束该 oid 的可拾取/追踪状态，播放宠物拾取淡出并从地图对象表删除；宠物表现对象暂时不可用也不影响删除收敛。

装备栏宠物页只显示当前已召唤宠物的内建能力与实际装备能力；现金栏中仅持有未召唤宠物不会点亮能力图标。

## 自动补给

- 玩家既可把 USE 栏中具备对应恢复效果的药水拖到宠物装备页 HP 或 MP 槽，也可在系统菜单的宠物自动补给面板中按当前背包候选切换；选择 `OFF` 可单独关闭 HP 或 MP 自动药水。药品选择按角色保存在服务端键位数据中。
- 宠物自动补给面板同时配置 HP/MP 触发阈值，范围 1%–99%、默认 50%，阈值保存在当前浏览器本地存储中。
- 只有角色存活、宠物已召唤、对应自动药水能力存在且实时背包仍有选中药水时才发送请求。
- 单个请求只消耗一个药水；同一药水同时恢复 HP/MP 时合并为一次请求，分别选药时 HP 优先、MP 在后续冷却允许时处理。

## 温饱度与饥饿状态

- 客户端策略阈值：温饱度低于 40 即进入饥饿状态（`pet_vitality::HUNGRY_THRESHOLD`）。
- 饥饿罢工：宠物照常跟随主人，但停止自动拾取与自动 HP/MP 药水补给；喂食恢复后自动复工，无需重新召唤。
- 喂食入口：双击 USE 栏 212 段宠物食品即发送 PET_FOOD（0x4C：timestamp + 物品栏位 + 物品 ID）；服务器自动喂给当前最饿的已召唤宠物（+温饱度，可能触发升级）。
- 状态展示：宠物自动补给面板顶部实时显示宠物名字、等级与温饱度，饥饿时橙色 HUNGRY! 提示；CASH 栏中饥饿宠物图标带红色 ! 角标；宠物升级时聊天栏播报。
- 与服务端并存：linked server 在温饱度降至 ≤5 时强制收回宠物（客户端收到后弹出橙色提示），收回后温饱度重置为 15，仍处于饥饿态，引导玩家喂食。

## 状态与错误

- 存量角色现金栏已满时不发放任何部分礼包，提示至少腾出一格并在下次登录重试。
- 本地阈值读取失败回到 50%；保存失败直接提示且不更新当前运行时阈值。
- 打开设置或确认保存时会重新校验药品仍存在且具有对应恢复效果；已移除或不匹配的选择转为 `OFF`，不会向服务端提交无效物品。
- 服务端补发事务或角色加载失败时终止本次登录，不以缺失能力的降级状态继续。
- 单个掉落的拾取动画目标缺失时改为原地淡出；未知掉落移除模式记录警告并立即删除服务端指定 oid，不允许已到账物品继续留在地图或被宠物重复追踪。

## 约束

- 不修改存量角色四维；所有新角色创建配方继续初始化 STR/DEX/INT/LUK 为 20。
- 使用现有 v83 宠物、能力、宠物装备页和物品图标，不新增游戏资源。
- 上线前必须先应用 linked server 的 `characters.starter_pet_grant_version` 迁移。
