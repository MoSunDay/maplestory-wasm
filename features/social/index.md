# 好友与组队

## 能力

登录角色可通过独立 Buddy 窗口维护好友，并通过现有 Party 窗口完成队伍生命周期。好友和队伍状态在窗口关闭时仍持续同步；重新打开窗口会显示最新状态。

## 好友

- R 打开或关闭 Buddy 窗口；可输入 3–12 字节合法角色名发送申请。
- 被申请方可在状态消息或 Buddy 窗口接受、拒绝；接受后双方获得可见好友条目。
- 好友条目显示在线频道或 Offline，并随登录、断线实时更新。
- 选中好友后可删除；拒绝申请不会把双方留在已接受状态。
- `/buddy <message>` 或 `/b <message>` 向当前好友列表发送好友聊天；没有好友时显示明确提示。

## 组队

- P 打开 Party 窗口；也可用 `/party create`、`invite`、`accept`、`deny`、`leave`、`expel`、`leader` 和 `list`。
- 新手角色允许与同一新手等级范围的角色组队；服务端仍负责等级、在线、频道、满员和邀请冲突校验。
- 成员加入后双方收到完整成员快照；界面同步队长、职业、等级、频道、地图与可用 HP。
- 队长可转让队长或踢出成员；最后一名成员退出后队伍解散。
- `/pt <message>` 或聊天目标 Party 发送队聊；未入队时显示明确提示。

## 人物信息

- 双击本人或地图中的其他玩家打开老版人物信息卡片；远端单击仍选择队伍目标，右键仍打开即时交易菜单。
- 卡片显示外观、等级、职业、人气、公会、联盟和婚姻状态；有已召唤宠物时可在人物卡正下方展开宠物面板并切换最多三只宠物，查看名称、等级、亲密度、饱食度和装备。
- 本人卡片只读；他人卡片可发起交易、增加人气或降低人气。人气限制和持久化结果以 linked server 响应为准，等待或失败不会禁用全局 UI。

## 状态与错误

好友请求和组队邀请分别保存，可同时存在并分别接受或拒绝。服务端拒绝、目标离线、好友/队伍已满、邀请冲突和队长操作限制均通过聊天状态行反馈；后续服务端快照会收敛客户端显示。
